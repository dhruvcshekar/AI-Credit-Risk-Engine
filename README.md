# AI-Credit-Risk-Engine
Developed a Credit Risk Engine (0.77 ROC-AUC) using FICO HELOC data. Engineered alternative data features (Gig-income/Utility history) and enforced Monotonic Constraints for regulatory logic. Integrated SHAP to automate "Reason Codes" for loan rejections, bridging the gap between high-performance ML and financial/legal compliance
